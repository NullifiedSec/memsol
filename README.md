# memsol

Hyprland-native resource orchestration for Arch Linux and CachyOS.

memsol is being built around one principle: optimize for effective capacity and perceived latency, not minimum memory usage.

The project will combine Hyprland attention signals, Linux cgroup v2/PSI telemetry, adaptive reclaim, application nap states, intentful workspaces, and browser-aware suspension into one explainable local policy engine.

> Status: early bootstrap. The first implementation phase is observer-only; it must measure and explain before it is allowed to reclaim or freeze anything.
